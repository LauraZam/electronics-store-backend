# Online Electronics Store REST API

Enterprise-grade RESTful API for an Online Electronics Store built with Java 21, Spring Boot 3.x, PostgreSQL, Hibernate/JPA, and JWT Authentication.

---

## Technical Stack

* **Java**: 21
* **Framework**: Spring Boot 3.x (Spring Web, Spring Security, Spring Data JPA)
* **Database**: PostgreSQL 15 (Docker containerized)
* **Authentication**: JJWT 0.12.x (Stateless Bearer Tokens)
* **Build Tool**: Maven

---
